# LegalEase

AI-Powered Legal Document Generator.

## Technology

- Python
- FastAPI
- Streamlit
- Google Gemini
- python-docx
- FPDF
- Pydantic

## Features

- AI legal-document drafting
- Employment contracts
- NDAs
- Lease agreements
- Freelance contracts
- Editable preview
- TXT export
- DOCX export
- PDF export
- Logo branding
- Footer
- Terms table
- FastAPI REST API
- Automated tests
